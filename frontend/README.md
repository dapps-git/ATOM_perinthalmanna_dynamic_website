# Atom Institute - Next.js Frontend Framework

This folder contains the Next.js UI structure for the Atom Institute website (Perinthalmanna).

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the site.

## Connected Services

- Backend API: `http://localhost:5000/api`
- Admin Portal: `http://localhost:5173`
- Blog & News APIs consume auto-converted **WebP** images from Cloudinary or backend upload storage.
